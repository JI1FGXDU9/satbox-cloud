# SatBox Cloud

SatBox Cloudは、アマチュア衛星の通過予測とAOS通知を、スマートフォンやパソコンのブラウザーで利用できるWebアプリケーションです。

**[SatBox Cloudを利用する](https://ji1fgx.com/satbox)**

SatBoxの機能のうち、衛星の通過予測とAOS通知に特化したWeb版です。無線機のドプラー制御やローテーター制御は含みません。専用Androidアプリのインストールは不要です。iPhoneでは、Safariからホーム画面に追加して利用します。

## 主な機能

- ユーザーごとの観測地点（QTH）で衛星の通過を予測
- コールサイン、メールアドレス、緯度・経度、高度、タイムゾーン、グリッドロケーターを設定
- NASA.ALLに収録された衛星から観測対象を選択
- 通過中と今後24時間または48時間のPassを表示
- AOS／LOS時刻、最大仰角、AOS方位角、カウントダウンを確認
- 通過中の衛星名とカウントダウンを赤文字で表示し、LOSまでの残り時間を確認
- 衛星地図で通過中の対象衛星の位置・可視範囲・方位・仰角を確認
- 通知する衛星、通過時の最大仰角の下限、AOS何分前に通知するか、通知時間帯を設定
- 同じユーザーで複数のスマートフォンやパソコンを通知先に登録
- Web Push通知の送信回数と送信間隔を設定
- 通知をタップして、その衛星のPass詳細を表示
- 通知予定一覧で、これから送信される通知を確認
- Pass一覧を表示している間は、AOS前とAOS時の音声アナウンスにも対応
- 管理画面でユーザー・メールアドレスの確認、権限変更、一般ユーザーの削除、NASA.ALLの更新
- 日本語と英語の表示を切り替え

## 利用手順・マニュアル

初めて利用する場合は、ユーザー登録 → 衛星選択 → AOS通知設定 → 通知端末登録 → テスト通知の順に設定してください。

- [日本語の紹介・操作説明](https://ji1fgx.com/261008.html)
- [英語の紹介・操作説明](https://ji1fgx.com/en/261008.html)
- [日本語の詳細マニュアル・開発履歴](Manual/README_jp.md)
- [英語の詳細マニュアル](Manual/README.md)
- [サーバー設置手順](Manual/サーバー設置手順.md)
- [Web Push設定手順](Manual/WEB_PUSH設定手順.md)

Web Push通知を受け取るには、端末とブラウザーで通知を許可してください。音声アナウンスはPass一覧を開いている間の機能です。通知音や受信時刻は、端末の設定や通信状況によって変わります。
